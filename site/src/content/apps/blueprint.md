# Blueprint (Structured Diagrams)


A typed graph diagram editor for flowcharts, org charts, ERDs, mindmaps, and more — where every node and edge is a queryable, MCP-addressable record.

- React Flow canvas with custom node shapes per diagram type
- ELK auto-layout (layered, force, tree, radial, rectangle-packing)
- 20 MCP tools so agents can build, query, or rewrite a whole diagram in one call
- Cross-product entity references — link a node to a Bam task, Beacon entry, Bond deal, or Bearing goal
