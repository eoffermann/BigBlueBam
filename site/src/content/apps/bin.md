# Bin (Digital Asset Management)


The drive that isn't just a drive: upload anything, get it scanned, versioned, foldered, and tagged, then opened in the right editor.

- Upload any file straight to object storage (MinIO/S3), with no arbitrary size ceilings
- Every upload is virus-scanned on the way in, so clean files go live and suspect ones get quarantined
- Re-uploads become versions instead of silent overwrites, so nothing you had yesterday disappears today
- Organize with nested folders and cross-cutting tags, and find assets by either
- Open datasets (CSV, JSON, YAML) in a live structured-data grid and tree editor with real-time co-editing
- Hand media and 3D models off to Bay for review and approval without leaving the workflow
- Serve as the storage backbone the rest of the suite stands on, holding the bytes behind Bay and Blip
- Let AI agents upload, version, tag, move, fetch, and edit structured data through 19 MCP tools, gated by visibility preflight and agent policies
